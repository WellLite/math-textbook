# 从“一个也没有”和“再添一个”出发

今天桌上一个贝壳都没有，记作 $0$。放上一个，得到 $0$ 的下一个数量；再放一个，又得到下一个数量。即使还没有“七十九”这个名字，也知道怎样在任何已经数到的地方再往前走一步。把“取下一个”暂记作 $S$，那么 $1=S(0)$，$2=S(1)$，$3=S(2)$。本书把 $0$ 算作自然数。

怎样规定这条数列，才能一直用来[计数](count.md)？首先，$0$ 是一个数，每个自然数 $n$ 都有一个确定的后继 $S(n)$。光有这两条还不够。钟面上的数也各有“下一格”，但走一圈会回到起点。我们补上：$0$ 不是任何数的后继，而且如果 $S(a)=S(b)$，那么 $a=b$。后一句说，在两个不同数量上各添一个，不会把原来的差别抹掉。假如从 0 出发的两步和五步落到同一点，逐次去掉双方相同的一步，最后会逼出 0 是某个数的后继。

还有个不容易想到的漏洞。可以画一条从 0 开始的长链，又在纸边另画一条永远接不到它的链，给那条链也定义后继。刚才几条局部规则未必能赶走它。我们真正要的是由起点和后继生成的那些数。于是加上**归纳原理**：自然数的一个子集只要包含 $0$，且每当它含 $n$ 就也含 $S(n)$，它就包含全部自然数。这一组关于 $0$、后继和归纳的约定是刻画自然数的一种方式。这里的“数”和“后继”是从规则出发的基本对象。

这些规则既可以拿来证明，也可以拿来造东西。例如给每个数安排一个记号：先定 $0$ 对应什么，再给一条从当前记号产生下一个记号的确定规则。自然数的**递归原理**保证这样能给每个数恰好一个记号。直观原因是每个数从 0 沿唯一的有限链到达，不会出现某一步要等自己的答案。下一篇会用这个原则，把“把一堆添到另一堆”写成[加法](add.md)。
