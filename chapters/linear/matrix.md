# 每一列究竟记录谁的去向

两种灯光强度分别调到 $s,t$，三个探头会给出三个读数。把两个旋钮都关掉时读数为零。经过实验，单独调强度会按比例放大各读数，同时开灯的读数等于两套单灯读数之和。现在给第一盏单位强度，读到 $(2,1,0)$；给第二盏单位强度，读到 $(1,0,3)$。还用为每个新设置再做一次实验吗？

为保留哪一项来自哪一盏灯，把一盏灯的三个读数竖着写成一列，两列并排，得到矩阵
$$A=\begin{pmatrix}2&1\\1&0\\0&3\end{pmatrix}.$$
先想旋钮，设置 $(3,2)$ 就是三份第一种单位输入与两份第二种单位输入。根据实验假设，输出为 $3(2,1,0)+2(1,0,3)=(8,3,6)$。再想探头，第一个读数只需读第一行，算 $2\times3+1\times2=8$。按列拼配方和逐行算读数，是同一次计算的两种读法。

**选定输入与输出各自的一组有序基，第 $j$ 列装的是第 $j$ 个输入基向量的像在输出基下的坐标。** 因此从两个自由参数到三个读数的矩阵有三行两列，纵横的位置各自有意义。把两盏灯的编号交换，矩阵的两列要交换，输入坐标中两项也要交换，同一次实验的预报值才会保持一致。如果探头饱和到一定亮度就停止增长，单灯加倍也无法保证读数加倍，这些校准数据便不足以决定其余设置。再接一台线性设备，会用到[矩阵乘法](../matrix-multiplication.md)。

### 若两套灯同时工作，矩阵该怎样相加？

另一组灯也接受同样的两个旋钮信号，三个探头的附加读数由矩阵 $B$ 给出。总读数应该是 $Ax+Bx$。希望用一张表 $C$ 代替两套，只需再做单位输入实验。喂入第 $j$ 个单位向量，输出就是 $A$、$B$ 的第 $j$ 列相加，于是 $C$ 的各项必须满足 $c_{ij}=a_{ij}+b_{ij}$。这就引出了同形矩阵的加法。若两张表中的行代表不同探头，或两张表本就大小不同，逐格相加便失去这项解释。把每项读数统一放大 $k$ 倍同理给出矩阵的数乘。
