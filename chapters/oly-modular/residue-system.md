# 一共十二个钟点，为何某些计算只用四个？

给所有整数贴钟点标签，只要相差 $12$ 的倍数就贴同一号。整数 $-1,11,23$ 得同一号，我们只要任选一个代表去算。把每个标签各选一次，就是模 $12$ 的完全剩余系，比如 $0,1,\ldots,11$，也可以用 $-5,-4,\ldots,6$。关键是每类一次，而非代表们都必须小于 $12$。

现在让每个代表乘 $5$。若 $5a\equiv5b\pmod{12}$，因 $5$ 与 $12$ 互素，便有 $a\equiv b$。所以一个有十二个不同标签的表仍获十二种不同标签，只是重排了一次。改乘 $4$ 时，$0,3,6,9$ 却都变成 $0$，重排失败。

哪些标签本身能做这样可撤销的乘法？恰好是与 $12$ 互素的 $1,5,7,11$；裴蜀等式保证它们各有模逆元。只从这些类里各取一个代表，叫简化剩余系。**完整的一圈用于记录所有可能的余数；可逆的那一部分会在相乘以后封闭，适合追踪乘幂。** 例如乘 $5$ 把上述四个数送到 $5,1,11,7$，这一次重排将成为[欧拉定理](fermat.md)的证明。
