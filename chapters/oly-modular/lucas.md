# 为什么杨辉三角模素数后，会一块一块地重复？

想求 $\binom{14}{5}$ 的奇偶性。把 $14$ 写成二进制 $1110$，$5$ 写成 $0101$。二者的最低位冲突，但位数与组合数有什么关系？回到生成组合数的式子 $(1+x)^{14}$。模 $2$ 时 $(1+x)^2\equiv1+x^2$，反复平方得 $(1+x)^8\equiv1+x^8$。所以 $(1+x)^{14}\equiv(1+x^8)(1+x^4)(1+x^2)$，选不出 $x^5$，组合数为偶数。

对素数 $p$，$(1+x)^p\equiv1+x^p\pmod p$，因为中间的二项式系数都含 $p$。写 $n=\sum n_ip^i,\ k=\sum k_ip^i$，便可将生成式拆成 $\prod_i(1+x^{p^i})^{n_i}$。每项提供的份数小于 $p$，凑出 $x^k$ 只有逐位取 $k_i$ 一法。故 $\binom nk\equiv\prod_i\binom{n_i}{k_i}\pmod p$，约定选过头的系数为零。这叫卢卡斯定理。

若问究竟含几个 $p$，用 $n!/[k!(n-k)!]$ 和[阶乘赋值](factorial-valuation.md)。第 $j$ 层贡献 $\lfloor n/p^j\rfloor-\lfloor k/p^j\rfloor-\lfloor(n-k)/p^j\rfloor$，等于低 $j$ 位相加是否向第 $j$ 位送来一个进位。**每一次进位贡献一个因子 $p$，并且恰好计一次。** 这就是库默定理。例中 $5+9=0101+1001=1110$，只在个位出一次进位，故 $\binom{14}{5}=2002$ 能被 $2$ 整除而不能被 $4$ 整除。
