# 把地图上绕回来的那一段剪掉

沿路线 $A,B,C,B,D$ 能从 $A$ 到 $D$。中间两次来到 $B$，就算整段 $B,C,B$ 都不走，仍有 $A,B,D$。把沿边行走的顶点序列称为游走；每发现一个重复顶点，就删去两次出现之间的绕行。长度每次减少，最后得到顶点互异的路径。这样只要能到达，便有一条不用重复经过任何点的路。

在无向图中，“能到达”可以反向走，也能把两条路接在一起，因此把所有点分成互不相交的连通分量。若回到起点且除首尾之外顶点互异，长至少三条边，就得到圈。设图上有三角形 $ABC$，再接边 $CD$ 和 $DE$。剪掉 $AB$，可沿 $A,C,B$ 绕行，分量仍有一个；剪掉 $CD$，两部分分离，此边叫桥。剪掉 $C$ 会增加分量数，是割点。

**一条无向边为桥，当且仅当它不在任何圈上。** 若在圈上，剩下的弧能接回两端；若删掉边后两端仍相通，将那条替代路径与被删边接起来，本来就有一个圈。于是局部的一圈和全图能否被一刀剪开的性质联系起来。
