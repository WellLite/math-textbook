# 怎样把一件事问成数学问题？

桌上放着三根一样长的木条。你把它们首尾相接围成一个三角形，叫一只小虫沿着木条走，一直走回出发的地方。我问它走了多远。你沿三条边描了一圈，说“有三根木条那么长”。我把尺的一端按在小虫出发的地方，另一端去找它停下的地方，两端碰在了一起。我说“零”。要判断谁答对，得先说清这把尺究竟要量什么。

把问题说得具体一点。小虫要沿着三根木条从头走到尾，每根长两厘米，每根恰好走一次，转弯不另算路程。只记沿途走过多少，得到 $2+2+2=6$ 厘米。**我们丢掉了木条的颜色、粗细和转角，因为在这一组约定下，改变那些东西不会改变答案**。这份有取舍的描述就是一个**模型**。式中的加法可以在[加法](../numbers/add.md)从计数重新建立。

如果用这三根木条铺一道直篱笆，想知道能挡住多宽的缺口呢？工人要把相邻两根各重叠半厘米。从尺上的零刻度起铺，第一根的右端到 2。第二根从 $1\frac12$ 开始，右端到 $3\frac12$。第三根从 3 开始，右端到 5。原来的算式把两段接头各数了两遍，所以实际覆盖 $6-\tfrac12-\tfrac12=5$ 厘米。拿同一把尺，却要换一种算法，因为问题已经变了。

这个例子可以往前走一步。假设直排 $n$ 根，每根长 $L$，每接一根新木条就和上一根重叠 $s$，它往前只延伸 $L-s$。第一根贡献 $L$，其余有 $n-1$ 根，所以总覆盖长为 $L+(n-1)(L-s)$。这里 $n$ 至少是 1，且按约定 $0\le s<L$。取 $n=1$，果然没有接头。若把木条弯回来，后段可能压到前面很远的部分，式子计算的“直排总长”就不能直接拿来回答“地面覆盖多大”。

读另一道题时，也可以动手改一个条件，问答案会不会跟着改。这常能揭示哪些信息真正进入了推理。
