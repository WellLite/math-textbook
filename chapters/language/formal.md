# 推理的规则本身，能拿来研究吗？

箱子上贴着“灯亮了就表示箱盖已关好”，眼前这盏灯也确实亮着。即使不知道里面装的是什么，我们也能从说明推出“箱盖已关好”。把“灯亮”换成 $P$，“关好”换成 $Q$，这一步只靠 $P$ 与 $P\Rightarrow Q$ 的形式。研究这样的语言、真假解释与推导规则，就进入了数理逻辑。

先做一种小得能逐项检查的语言。允许用 $P,Q$ 两个字母，给它们分别赋真或假。用 $\neg P$ 表示“$P$ 不成立”，用 $P\land Q$ 表示“两者都成立”。约定 $P\Rightarrow Q$ 只有在 $P$ 真而 $Q$ 假时为假。把四种赋值都写进表中。

| $P$ | $Q$ | $P\Rightarrow Q$ | 两条前提 $P$ 与 $P\Rightarrow Q$ 都真？ |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 是 |
| 真 | 假 | 假 | 否 |
| 假 | 真 | 真 | 否 |
| 假 | 假 | 真 | 否 |

能够同时兑现两条前提的只有第一行，那一行的 $Q$ 确实为真。于是只要前提为真，照这条规则走就总能得到真结论，称为**保持真**。这不保证某个实际箱子的说明书写得正确。若有人误把 $Q$ 与 $P\Rightarrow Q$ 当成推出 $P$ 的前提，表中的第三行马上提供反例。

再给箱子添一盏绿灯，$R$ 表示“绿灯亮”。把三条前提写在纸上，随后每添一行都注明出处。

| 行 | 写下的公式 | 凭据 |
| --- | --- | --- |
| 1 | $P$ | 前提 |
| 2 | $P\Rightarrow Q$ | 前提 |
| 3 | $Q\Rightarrow R$ | 前提 |
| 4 | $Q$ | 对第 1、2 行使用刚才检验过的规则 |
| 5 | $R$ | 对第 4、3 行使用同一条规则 |

这样的记录叫**形式推导**。遮住“灯”和“箱盖”的意思，读者仍能逐行核对符号是否合乎规则。重新让字母代表具体事实，又能解释推导为什么值得信任。只要前三行碰巧都真，第四行必须真，第五行也真。每一条获准使用的规则若都保持真，有限多步接起来仍保持真，这叫这套规则的**可靠性**。还可以把问题倒过来。如果一个结论在所有满足前提的解释里都为真，给定的规则是否一定能推出它？这是另一项要另给论证的性质，叫**完备性**。

要谈“每一辆车都有一个车牌”这样的句子，还得指定对象的范围，给性质、关系以及[量词](quant.md)意义。刚才四行表覆盖的是两个命题字母的情形。普通数学的全称断言往往涉及无限多个对象。
