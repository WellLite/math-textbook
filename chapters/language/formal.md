# 推理的规则本身，能拿来研究吗？

箱子上贴着“灯亮了就表示箱盖已关好”，眼前这盏灯也确实亮着。即使不知道里面装的是什么，我们也能从说明推出“箱盖已关好”。把“灯亮”换成 $P$，“关好”换成 $Q$，这一步只靠 $P$ 与 $P\Rightarrow Q$ 的形式。若要把这一步用到别的事情上，先得问它会不会把两句真话带成一句假话。有这样的情形，一个就足以让我们舍掉这条推理规则。

先做一种小得能逐项检查的语言。允许用 $P,Q$ 两个字母，给它们分别赋真或假。用 $\neg P$ 表示“$P$ 不成立”，用 $P\land Q$ 表示“两者都成立”。按[条件句](statement.md)的含义，$P\Rightarrow Q$ 只有在 $P$ 真而 $Q$ 假时为假。坏情形到哪里找？$P$ 取真或假，各自又配上 $Q$ 的真或假，一共四种。干脆列一张**真值表**，在每种情形下对照前提和结论。

| $P$ | $Q$ | $P\Rightarrow Q$ | 两条前提 $P$ 与 $P\Rightarrow Q$ 都真？ |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 是 |
| 真 | 假 | 假 | 否 |
| 假 | 真 | 真 | 否 |
| 假 | 假 | 真 | 否 |

能够同时兑现两条前提的只有第一行，那一行的 $Q$ 确实为真。于是只要前提为真，照这条规则走就总能得到真结论，称为**保持真**。这不保证某个实际箱子的说明书写得正确。若有人误把 $Q$ 与 $P\Rightarrow Q$ 当成推出 $P$ 的前提，表中的第三行马上提供反例。

再给箱子添一盏绿灯，$R$ 表示“绿灯亮”。把三条前提写在纸上，随后每添一行都注明出处。

| 行 | 写下的公式 | 凭据 |
| --- | --- | --- |
| 1 | $P$ | 前提 |
| 2 | $P\Rightarrow Q$ | 前提 |
| 3 | $Q\Rightarrow R$ | 前提 |
| 4 | $Q$ | 对第 1、2 行使用刚才检验过的规则 |
| 5 | $R$ | 对第 4、3 行使用同一条规则 |

这样的记录叫**形式推导**。遮住“灯”和“箱盖”的意思，读者仍能逐行核对符号是否合乎规则。重新让字母代表具体事实，又能解释推导为什么值得信任。如果前三行都真，第四行必须真，第五行也真。**每一步都保持真，走有限多步仍会保持真。这样，从真前提出发，推导就不会给出假结论，这叫可靠性。**

这套规则会漏掉应当能写出来的结论吗？假如纸上最初只写着 $P$ 和 $Q$，我们当然知道，两者都真时，“$P$ 并且 $Q$”也真。可要是工具箱里只有上面那条规则，它需要一条形如“如果……那么……”的前提，纸上连这样的第一步都凑不出来。我们想要一套足够丰富的规则，使得凡是在所有满足前提的解释里都为真的结论，都能从前提一步步写出来。这项要求叫作**完备性**。能否做到，要针对所选的语言和规则给出证明。

把语言本身、句子的真假和获准的推导放在一起研究，就是数理逻辑要做的事。要谈“每一辆车都有一个车牌”这样的句子，还得指定对象的范围，给性质、关系以及[量词](quant.md)意义。刚才四行表覆盖的是两个命题字母的情形。普通数学的全称断言往往涉及无限多个对象。
