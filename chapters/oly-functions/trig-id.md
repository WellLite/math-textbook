# 两个角的正弦，怎样合成一次可以解的比较？

解 $\sin3x=\sin x$。若分别除以 $\sin x$，$x=0$ 这个现成的解立刻被排除。把两边移到同侧，若能变成乘积为零，每个因子都能给出一族解。两个角的中点是 $2x$，向两边各移 $x$；用和差角公式展开 $\sin(2x+x)-\sin(2x-x)$，共同部分消去，得到 $2\cos2x\sin x$。

因此 $\sin x=0$ 或 $\cos2x=0$，即 $x=k\pi$ 或 $x=\pi/4+k\pi/2$，$k$ 为任意整数。把角换成 $u,v$，同一中点操作给
$$\sin u-\sin v=2\cos\frac{u+v}{2}\sin\frac{u-v}{2}.$$
两式改为相加就得到正弦和的化积。把各项搬回去也能积化和差，例如 $2\sin u\cos v=\sin(u+v)+\sin(u-v)$。倍角式 $\sin2u=2\sin u\cos u$ 则是把同一个角相加的特例。

**先看希望得到的是“某个因子为零”，还是“两个频率的和”，变换方向便有了理由。** 解周期方程时还应把角度范围带回来。例如原题若限 $0\le x<\pi$，保留的只有 $0,\pi/4,3\pi/4$。
