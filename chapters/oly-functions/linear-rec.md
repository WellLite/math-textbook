# 为什么试一列等比数？

一列数满足 $a_{n+2}=5a_{n+1}-6a_n$，给定 $a_0=1,a_1=4$。直接向前推可以得到任意指定一项，却看不清第 $100$ 项的结构。什么数列平移下标以后会保留原来的形状？每步乘同一个数的数列恰有这个性质。试 $a_n=r^n$，要让关系成立，正好需要 $r^2-5r+6=0$，即 $r=2,3$。

递推式两边都只作线性运算，所以 $A2^n+B3^n$ 也满足同式。用初值解 $A+B=1,\ 2A+3B=4$，得 $A=-1,B=2$。与原序列的前两项相同，递推唯一性就保证此式给出全部项。**两个互异特征根提供两种独立形状，两个初值决定如何混合它们。**

若方程只有重根 $r\ne0$，一个 $r^n$ 装不下两份初值。此时试 $a_n=r^nb_n$，原递推 $a_{n+2}=2ra_{n+1}-r^2a_n$ 化为 $b_{n+2}-b_{n+1}=b_{n+1}-b_n$，故 $b_n=A+Bn$。一阶式 $a_{n+1}=ra_n+s$ 则可先减去定点 $L=rL+s$ 再化成等比，$r=1$ 时直接等差。斐波那契递推的特征方程相应为 $r^2=r+1$。

若想从几组不同初值亲自发现“两个解的和仍是解”，可以比较 Levin 给出的三列实验数据。[《Discrete Mathematics: An Open Introduction》§2.4](https://discrete.openmathbooks.org/dmoi3/sec_recurrence.html)
