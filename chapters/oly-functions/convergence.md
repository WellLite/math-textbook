# 看见定点以后，数列一定到得了那里？

取 $a_0=0,\ a_{n+1}=\sqrt{2+a_n}$，前几项从 $0$ 上升到接近 $2$。若极限 $L$ 存在，根号函数连续，就应有 $L^2-L-2=0$。其中 $-1$ 连非负条件也不满足。可是把 $2$ 代回递推，只能说明到达 $2$ 会留在那里，还没有说明从零出发会越来越接近它。

先造一道栏杆。若 $0\le a_n\le2$，则 $0\le a_{n+1}\le2$，归纳可知始终如此。在这一区间，$2+x-x^2=(2-x)(1+x)\ge0$，开平方说明下一项不少于本项。因此数列单调有界。为什么这保证收敛？取所有项的最小上界 $s$（它的存在正用到[实数的完备性](../analysis/real.md)）；任给 $\varepsilon>0$，一定有一项超过 $s-\varepsilon$，否则它就是更小的上界。往后各项都夹在 $s-\varepsilon$ 与 $s$ 间，极限便是 $s$。此时才可用定点方程得 $s=2$。

**先证明脚步会聚到一起，再用递推辨认聚集的位置。** 反例 $b_{n+1}=1-b_n,\ b_0=0$ 虽有定点 $1/2$，轨道却在零与一之间往返。甚至有界性也不足以代替收敛论证。
