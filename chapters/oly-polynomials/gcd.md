# 共同的因子为什么会跟着余数走？

要找 $x^3-1$ 与 $x^2-1$ 共有的最大次数首一因式。分解两式是一条路，可是遇到还不会分解的高次式就停下了。观察任何同时整除两式的多项式 $D$：它也一定整除 $(x^3-1)-x(x^2-1)=x-1$。反过来，若 $D$ 整除 $x^2-1$ 与 $x-1$，把刚才减去的倍数加回，又得到它整除 $x^3-1$。

于是用“除式、余式”替换“被除式、除式”不会丢失任何公因式，而且次数在下降。现在 $x^2-1=(x+1)(x-1)$ 余零，最后的非零余式 $x-1$ 就是最大公因式，通常调成首一以消除非零常数倍的歧义。这是系数可作除法的[域](../structures/fields.md)上的辗转相除。

把各步倒过来代入，可以将最大公因式写成两个原式的多项式倍数之和。比如 $x$ 与 $x^2+1$ 有 $1=(x^2+1)-x\cdot x$。**这行裴蜀等式既给出怎样拼出 $1$，也证明任何公因式只能是常数。** “没有共同实根”却不足以判互素，$x^2+1$ 和它的平方就没有实根，却共享整个二次因子。
