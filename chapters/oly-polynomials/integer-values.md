# 每个整数代入都成整数，系数也必须是整数吗？

从 $n$ 个人中选两人有 $n(n-1)/2$ 种方法。表达式中出现了半个单位，答案却总是整数，原来两个相邻整数里一定有一个偶数。于是“系数为整数”和“所有整数点的取值为整数”值得分别命名。后者称整值多项式，前者必然整值，逆命题已被这个例子推翻。

怎样判断一个有理系数的 $d$ 次多项式 $P$ 是否整值？对 $0,1,\ldots,d$ 检查，如果这些值都是整数，各阶前向差分 $\Delta^kP(0)$ 也都是整数。用[差分展开](difference.md)，剩下只需弄清 $\binom{x}{k}=x(x-1)\cdots(x-k+1)/k!$ 在整数处是否都整。非负整数对应选取的件数；若 $x=-m<0$，逐项提出负号得到 $(-1)^k\binom{m+k-1}{k}$，也整。

**连续的 $d+1$ 个整数取值足以检验整值性，因为它们决定了能在整数上安全使用的一套基底的全部系数。** 检查点如果分散就会失灵：$P(x)=x/2$ 在 $0,2$ 都取整数，在中间的 $1$ 却失败。
