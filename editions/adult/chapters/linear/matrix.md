# 矩阵怎样记录线性映射

一次线性测量有两个可独立设置的输入 $s,t$，输出是三个传感器的读数。第一种输入单独设为单位强度时测得 $(2,1,0)$，第二种单独设为单位强度时测得 $(1,0,3)$。要由这两次校准预测任意设置，必须知道测量具有叠加性：输入数乘使输出同比例缩放，两次输入之和的输出等于对应输出的和。在这个假设下，两次校准已经给出了每个输入方向的全部贡献。

将同一种单位输入对应的三个输出竖写成一列，两列并排，得到矩阵
$$A=\begin{pmatrix}2&1\\1&0\\0&3\end{pmatrix}.$$
按输入来读，设置 $(3,2)$ 就是三份第一种单位输入与两份第二种单位输入。根据实验假设，输出为 $3(2,1,0)+2(1,0,3)=(8,3,6)$。按输出来读，第一个读数只需读第一行，算 $2\times3+1\times2=8$。按列取线性组合和按行求各输出分量，是同一次计算的两种读法。

**选定输入与输出各自的一组有序基，第 $j$ 列装的是第 $j$ 个输入基向量的像在输出基下的坐标。** 因此从两个自由参数到三个读数的矩阵有三行两列，纵横的位置各自有意义。交换两种输入的次序，矩阵的两列要交换，输入坐标中两项也要交换，同一次实验的预报值才会保持一致。如果探头饱和到一定亮度就停止增长，单个输入加倍也无法保证读数加倍，这些校准数据便不足以决定其余设置。再接一台线性设备，会用到[矩阵乘法](../matrix-multiplication.md)。

### 若两组输出叠加，矩阵该怎样相加？

另一台设备也接收相同的两个输入，三个探头的附加读数由矩阵 $B$ 给出。总读数应该是 $Ax+Bx$。希望用一张表 $C$ 代替两套，只需再做单位输入实验。令输入为第 $j$ 个单位向量，输出就是 $A$、$B$ 的第 $j$ 列相加，于是 $C$ 的各项必须满足 $c_{ij}=a_{ij}+b_{ij}$。这就引出了同形矩阵的加法。若两张表中的行代表不同探头，或两张表本就大小不同，逐格相加便失去这项解释。把每项读数统一放大 $k$ 倍同理给出矩阵的数乘。
