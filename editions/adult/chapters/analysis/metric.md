# 如何度量函数之间的误差

对于 $[0,1]$ 上的两个连续函数 $f,g$，能否用一个数表达整段上的误差？有向差的积分可能因正负抵消而为零，例如取 $f(t)=t-1/2,g(t)=0$，两函数分明不同。若需要保证每一处的误差都小，一个直接的选法是 $d(f,g)=\max_{0\le t\le1}|f(t)-g(t)|$。连续函数在闭区间上能取到最大值，因此这个数确实存在。

这个“距离”非负，等于零恰好意味着两条曲线处处相等，交换曲线不变。引入第三个连续函数 $h$，每个时刻都有 $|f(t)-g(t)|\le |f(t)-h(t)|+|h(t)-g(t)|$；取最大值后得 $d(f,g)\le d(f,h)+d(h,g)$。只要一套距离满足这几条规则，就得到一个**度量空间**。点可以是数、图形，乃至整条连续函数。点列 $x_n$ 收敛到 $x$，就是 $d(x_n,x)\to0$。

若还不知道应当靠近哪一个点，可以互相比较足够晚的两项。对每个 $\varepsilon>0$，若有 $N$ 使 $m,n\ge N$ 时 $d(x_m,x_n)<\varepsilon$，就叫**柯西列**。有极限一定如此，取后期两项各距极限不到 $\varepsilon/2$ 即可。逆向还需要空间完备，意思是每个柯西列都有空间内的极限。例如在 $(0,1)$ 内取 $x_n=1/(n+1)$，后期任意两项差都很小，本应接近的 $0$ 却被删掉了。**选距离决定怎样辨别误差，选空间还决定所逼近的对象是否被容许存在。**
