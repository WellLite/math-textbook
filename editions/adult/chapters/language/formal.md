# 推理规则本身为什么可信？

从“如果 $P$ 就有 $Q$”以及“$P$ 成立”推出 $Q$，似乎无需知道 $P,Q$ 谈论什么。要证明这条规则可以替换到任何场合，就检查有没有可能让两条前提同时为真而结论为假。这里每个字母只有真假两种取值，给字母指定真假的方式叫作赋值。两个字母总共只有四种赋值，完全可以列尽。

| $P$ | $Q$ | $P\Rightarrow Q$ | $P$ 与 $P\Rightarrow Q$ 是否都真 |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 是 |
| 真 | 假 | 假 | 否 |
| 假 | 真 | 真 | 否 |
| 假 | 假 | 真 | 否 |

用到的规则是[条件句](statement.md)只在前件真而后件假时为假。表格这样列尽赋值及公式结果，叫作真值表。只有第一行使两个前提都真，这一行 $Q$ 果然也真。所以从 $P$ 与 $P\Rightarrow Q$ 推出 $Q$ 是一条**保持真**的规则。若改从 $Q$ 和 $P\Rightarrow Q$ 推出 $P$，第三行立即成为反例。

## 从一次推理到一份推导

现在给出 $P$、$P\Rightarrow Q$、$Q\Rightarrow R$，怎样把最终结论的来历写到任何人都能核对？

| 行 | 公式 | 依据 |
| --- | --- | --- |
| 1 | $P$ | 给定前提 |
| 2 | $P\Rightarrow Q$ | 给定前提 |
| 3 | $Q\Rightarrow R$ | 给定前提 |
| 4 | $Q$ | 对第 1、2 行应用上述规则 |
| 5 | $R$ | 对第 4、3 行应用同一规则 |

这样的有限记录叫形式推导。逐行检查时只需看符号形式与引用行号。另一个问题是，它在什么意义上保证结论成立？任选一个使三条前提都真的赋值，第 4 行保持真，第 5 行也保持真。对任意有限长的推导，可沿着同一道理逐行推进。**只要推导中允许的每条规则都保持真，从前提出发能推得的结论，就在每个使前提为真的解释中为真。** 这种性质叫可靠性。

反过来问：只用这些规则，是否能推得所有在前提为真时必真的结论？例如 $P,Q$ 都真时，$P\land Q$（“$P$ 且 $Q$”）当然为真。但若只允许刚才的规则，最初两行里根本没有形如条件句的公式，推导连一步都走不了。若要求这种意义下必真的结论都可推导，所要求的性质叫**完备性**。要达到它，需要给所用语言配备足够的规则。

数理逻辑把语言、解释和推导本身作为研究对象。例如 $\neg P$ 的真假总与 $P$ 相反，是一种联结词的解释；允许从什么公式写出什么新行，则是对推导的规定。若句子中还要表达“所有对象”或“存在对象”，就得给出对象的范围和[量词](quant.md)的解释，仅列两个命题字母的四种赋值已经不够。
