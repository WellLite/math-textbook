# 为什么余数能够替换较大的数？

怎样求 $84$ 与 $30$ 的最大公因数，又不必列举全部因数？先算 $84=2\cdot30+24$。若 $d$ 同时整除 $84$ 和 $30$，它也整除差 $84-2\cdot30=24$；反过来，若它整除 $30$ 与 $24$，也整除和 $2\cdot30+24=84$。**原来的一对数与新的一对数有完全相同的公因数。** 余数较小，替换又不丢失目标，因此值得继续。

这就有理由把 $(84,30)$ 换成 $(30,24)$。再算 $30=1\cdot24+6$，把它换成 $(24,6)$。这里 $24=4\cdot6$，公因数是六的所有正因数，最大的正是六。两个不同时为零的整数的这个最大公共正因数叫**最大公因数**，对负数可先取绝对值。若一数为零，另一数的绝对值自己就是答案。

一般每次写 $a=qb+r$，新的一对是 $(b,r)$。对任一公因数，$r=a-qb$ 与 $a=qb+r$ 说明了两向的整除。由[带余除法](euclidean-division.md)，余数在零与 $b$ 之间且严格小于 $b$，一串变小的非负整数不可能无限走下去。一直算到余数为零，最后一个非零余数就是所求。这个能停、停处又保住原问题答案的办法叫**欧几里得算法**。

刚才的算式还藏着别的信息。把最后的六往回代，$6=30-24=30-(84-2\cdot30)=3\cdot30-84$。也就是说，公因数六本身能由原来两数各乘一个整数再相加得到。每一步的余数都是前两数的整数线性组合，沿记录回代，任意两个起始数的最大公因数都能写成它们的整数线性组合。若最大公因数为一，这便提供了在[同余](mod.md)中寻找乘法逆元的办法。
